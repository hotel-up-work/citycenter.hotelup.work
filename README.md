На сторінці Hotels24.ua (`hotels24.ua/uk/Chernivtsi/Hotel-City-Center-Residence-7406.html`) фактично змішані два різні набори фото під двома старими назвами бренду — «Central Magnat **SPA**» (бакет `hotel_main/104/...`) і «Central Magnat **Cinema**» (бакет `room|facility/129/12971/...`). Адреса на сторінці (вул. Ольги Кобилянської, 36) збігається з нашою для обох наборів, але фасад у наборі SPA (портик із колонами) не відповідає реальній історичній будівлі — buд. №36 відомий як кінотеатр ім. Зої Космодем'янської, «Польський дім» 1902 року з вежею від 2-го поверху й балконами (джерело: suspilne.media). Набір **Cinema** збігається з цим описом (є навіть фото кінозали), тому з 2026-10-06 використовується лише він; набір SPA видалено з сайту як, найімовірніше, фото іншого закладу.
